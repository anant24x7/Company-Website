Frequently Asked Questions

Can we move our existing ERP application to the cloud?

In many cases, yes. The application architecture, database requirements, integrations and licensing should first be assessed before migration.

Can you host both our application and database?

Yes. Depending on the architecture, application and database workloads can be deployed on suitable cloud services.

Do you provide Azure setup and support?

Yes. We can assist with Azure infrastructure, virtual machines, networking, application hosting, databases and related configuration.

Do you provide cloud backups?

Backup requirements can be included in the cloud architecture based on data criticality, recovery objectives and business needs.
